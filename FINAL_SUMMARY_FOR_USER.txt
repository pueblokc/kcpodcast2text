🚀 HOW TO CREATE THE EXECUTABLE (SUPER SIMPLE!)
================================================================================

WINDOWS USERS:
--------------
1. Install Python from: https://www.python.org/downloads/
   (Check "Add Python to PATH" during install)

2. Install FFmpeg from: https://ffmpeg.org/download.html

3. Double-click this file:
   build_windows.bat

4. Wait 5-10 minutes (grab coffee ☕)

5. Done! Your executable is at:
   dist\PodcastArchive.exe

6. Double-click PodcastArchive.exe to run!


MAC USERS:
----------
1. Open Terminal and run:
   brew install python@3.11
   brew install ffmpeg

2. Navigate to project:
   cd /path/to/kcpodcast2text

3. Build:
   chmod +x build_macos.sh
   ./build_macos.sh

4. Wait 5-10 minutes

5. Done! Your app is at:
   dist/Podcast Archive.app

6. Double-click to run!


LINUX USERS:
------------
1. Open Terminal and run:
   sudo apt install python3.11 python3.11-venv ffmpeg

2. Navigate to project:
   cd /path/to/kcpodcast2text

3. Build:
   chmod +x build_linux.sh
   ./build_linux.sh

4. Wait 5-10 minutes

5. Done! Your binary is at:
   dist/podcast-archive

6. Run: ./dist/podcast-archive
